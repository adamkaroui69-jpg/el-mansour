# ⚡ Quick Start - Démarrage Ultra-Rapide

**Objectif** : Être opérationnel en 10 minutes chrono !

---

## 1️⃣ Installation (2 min)

1. Double-cliquez sur `ElMansourSyndicManager-Setup.exe`
2. Suivez l'assistant → Suivant → Suivant → Installer
3. Lancez l'application

---

## 2️⃣ Première Connexion (1 min)

**Identifiant** : `admin`  
**Mot de passe** : `admin123`

⚠️ Changez-le immédiatement : Cliquez sur votre nom → Mon Profil → Changer le mot de passe

---

## 3️⃣ Ajouter un Résident (2 min)

1. Menu **"Résidents"** → **"+ Nouveau"**
2. Remplissez :
   - Code Maison : `A-101`
   - Nom : `Ahmed Ben Ali`
   - Téléphone : `98765432`
   - Cotisation : `200.00`
3. **Enregistrer**

---

## 4️⃣ Enregistrer un Paiement (2 min)

1. Menu **"Paiements"** → **"+ Nouveau"**
2. Sélectionnez le résident
3. Choisissez le mois : `Janvier 2026`
4. Montant : `200.00`
5. **Enregistrer**

✅ Un reçu PDF est généré automatiquement !

---

## 5️⃣ Activer les Sauvegardes (1 min)

1. **"Paramètres"** → **"Sauvegardes"**
2. Activez **"Sauvegarde automatique"**
3. Cliquez sur **"Sauvegarder Maintenant"**

---

## 6️⃣ Consulter le Tableau de Bord (1 min)

Cliquez sur **"Tableau de Bord"** pour voir :
- 💰 Total encaissé ce mois
- 📊 Nombre de paiements
- ⚠️ Arriérés

---

## 7️⃣ Exporter un Rapport (1 min)

1. Dans n'importe quelle vue, cliquez sur **"Exporter"**
2. Choisissez **Excel** ou **CSV**
3. Enregistrez

---

## ✅ Vous êtes Prêt !

**Prochaines étapes** :
- Importez tous vos résidents (CSV)
- Configurez le logo de la résidence
- Créez des utilisateurs supplémentaires

**Besoin d'aide ?** → [GUIDE_PREMIERE_UTILISATION.md](GUIDE_PREMIERE_UTILISATION.md)

---

## 🎯 Raccourcis Essentiels

| Action | Raccourci |
|--------|-----------|
| Nouveau | `Ctrl + N` |
| Enregistrer | `Ctrl + S` |
| Exporter | `Ctrl + E` |
| Actualiser | `F5` |

---

## 🆘 Problème ?

**L'app ne démarre pas** → Exécutez en tant qu'administrateur  
**Mot de passe oublié** → Utilisez `admin` / `admin123`  
**Erreur de base de données** → Vérifiez que SQL Server LocalDB est installé

**Plus d'aide** → [FAQ.md](FAQ.md)
