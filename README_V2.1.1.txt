NOUVEAUTÉS VERSION 2.1.1
=======================

1. CORRECTION CRASH
   Le problème de "Mise à jour de la base de données impossible" est corrigé.
   L'application utilise maintenant le dossier %AppData% pour stocker ses données locales.

2. SYNCHRONISATION CLOUD DISPONIBLE
   Vous pouvez maintenant connecter l'application à une base de données SQL Server (Azure, etc.) pour une synchronisation automatique via Internet.
   
   Instructions :
   a. Installez cette version 2.1.1.
   b. Lisez le document "GUIDE_CLOUD_SYNC.md" installé dans le dossier "Docs" de l'application (ou à la racine de l'installation).
   c. Modifiez le fichier appsettings.json pour y mettre votre chaîne de connexion Cloud.

3. AFFICHAGE CONFIGURATION
   Dans Paramètres, vous pouvez voir où se trouve votre base de données et quel mode est utilisé.
