# ☁️ RELEASE v2.1.2 - Supabase & PostgreSQL Support

**Version :** 2.1.2
**Date :** 22 Janvier 2026

## 🚀 Nouveautés

### Support de PostgreSQL & Supabase (Cloud Gratuit)
- L'application est maintenant compatible avec **PostgreSQL**.
- Vous pouvez utiliser **Supabase** (gratuit, rapide, backup auto) comme base de données Cloud.
- **Synchronisation Internet** : Tous les utilisateurs connectés voient les mêmes données en temps réel.
- Voir `GUIDE_CLOUD_SYNC.md` pour connecter votre compte Supabase.
