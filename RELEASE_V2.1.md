# 🚀 RELEASE NOTES - Version 2.1.0

**Date :** 15 Janvier 2026
**Version :** 2.1.0 (Major UI Overhaul)

## 🎨 Nouveautés Majeures

### 1. Nouvelle Interface Professionnelle
- **Design System Complet** : Adoption d'une charte graphique professionnelle (Bleu/Gris).
- **Mode Sombre Amélioré** : Remplacement des tons bleu marine par un gris anthracite élégant (#1E1E1E).
- **Mode Clair Épuré** : Interface blanche et bleue, inspirée des applications bancaires modernes.
- **Composants Modernes** : Nouvelles cartes, boutons, et champs de saisie avec effets de survol et focus.

### 2. Rapports Financiers
- **Nouveau Module** : Vue dédiée pour l'analyse financière.
- **Export Excel/CSV** : Possibilité d'exporter les données financières.
- **Indicateurs Clés (KPI)** : Affichage clair du Total Dû, Collecté, et Dépensé.

### 3. Améliorations UX
- **Navigation Fluide** : Barre latérale redessinée avec indicateurs de sélection clairs.
- **Notifications** : Nouveau panneau de notifications stylisé.
- **Dialogues Modaux** : Utilisation de fenêtres modales pour les confirmations et alertes.

## 🛠️ Correctifs Techniques

- **Résolution des conflits de styles** : Nettoyage des anciens ResourceDictionaries.
- **Correction du crash de navigation** : Réintégration des ressources manquantes.
- **Optimisation des performances** : Chargement plus rapide des vues.

## 📦 Installation et Déploiement

### Prérequis
- Windows 10 version 1809 ou supérieur.
- .NET 8.0 Desktop Runtime.

### Comment Installer
1. Exécutez le fichier `ElMansourSyndicManager-Setup-v2.1.0.exe`.
2. Suivez les instructions à l'écran.
